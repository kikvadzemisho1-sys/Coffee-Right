# Coffee Ride

Coffee Ride is a simple coffee shop website created with HTML and CSS.

## Features

- Modern coffee shop design
- Hero section
- About section
- Menu cards
- Why Choose Us section
- Gallery
- Contact form
- Footer navigation
- Smooth scrolling
- Hover effects

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Project Purpose

This project was created as a frontend practice project to improve my HTML and CSS skills.
